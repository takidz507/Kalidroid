# Roadmap

1. **Build and install validation** — run GitHub Actions, install the debug APK, validate the PRoot engine and Kali login on ARM64 Android.
2. **PTY terminal** — replace pipe-backed shell transport with a native PTY, add Ctrl-C, resize, ANSI rendering and proper session lifecycle.
3. **Tool manager** — browse and install packages through apt, show installed tools and disk usage.
4. **File manager** — navigate app-private Kali files, create/edit/delete files safely and share selected exports.
5. **Session history** — multiple sessions, command history, persistent preferences and crash-safe lifecycle.
6. **Release hardening** — dependency/license audit, reproducible builds, signing strategy and security review.
