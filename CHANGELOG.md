# Changelog

## 0.4.0
- Added a persistent interactive Kali `/bin/sh` session.
- Added connect/disconnect shell controls and streamed command output.
- Added native-library extraction packaging required to execute the PRoot binary from Android's native library directory.
- Updated project status and build documentation to state what is implemented and what remains unverified.

## 0.3.0
- Added Kali ARM64 Minimal rootfs installer and checksum verification.
- Added initial PRoot process adapter and terminal UI.
